# Database icons

These bundled marks identify the database engine used by each connection. Original brand colors are preserved in light and dark mode.

- Oracle: official website favicon, https://www.oracle.com/favicon.ico
- MongoDB: official website favicon, https://www.mongodb.com/assets/images/global/favicon.ico
  Brand reference: https://www.mongodb.com/company/newsroom/brand-resources
- SQLite: blue database/feather mark from the official website banner, https://www.sqlite.org/images/sqlite370_banner.svg
  The wordmark and white background were removed; the original mark paths and gradient are retained in sqlite.svg with a square viewBox. sqlite.png is a 128px AppKit rendering of that SVG for consistent support on macOS 14 and later.

Product names and marks belong to their respective owners.
